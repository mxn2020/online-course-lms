# Online Course / LMS Platform

## Pages & Features

### 1. Landing Page (Public)
- Course catalog with category & level filters
- Featured / trending courses
- Search with autocomplete
- Course preview cards (thumbnail, title, rating, price)

### 2. Course Detail (Public)
- Course description, syllabus, learning outcomes
- Instructor profile
- Reviews & ratings
- Enroll / purchase button
- Video preview

### 3. Student Dashboard
- Enrolled courses with progress bars
- Continue learning shortcut
- Upcoming deadlines & assignments
- Certificates earned
- Recommended courses

### 4. Course Player
- Video player with playback controls (speed, captions)
- Lesson sidebar navigation
- Mark lesson as complete
- Downloadable resources (PDFs, files)
- Notes per lesson (personal)
- Q&A / discussion per lesson

### 5. Assignments & Quizzes
- Quiz with multiple question types (MCQ, true/false, short answer)
- Auto-grading for objective questions
- Assignment submission (file upload, text entry)
- Instructor feedback & grading
- Attempt history & score tracking

### 6. Certificates
- Auto-generate certificate on course completion
- Certificate template with course & student details
- Download / share certificate
- Verification page with unique code

### 7. Instructor Dashboard
- Course creation & management
- Student enrollment stats
- Revenue & earnings overview
- Q&A inbox for their courses

### 8. Course Builder (Instructor)
- Drag-and-drop curriculum builder (sections → lessons)
- Upload video, text, or document lessons
- Add quizzes & assignments per section
- Set pricing (free / paid / subscription)
- Publish / unpublish course

### 9. Discussion Forum
- Course-specific discussion boards
- Post questions, upvote, comment
- Instructor-pinned answers
- Search & filter threads

### 10. Admin Panel
- User management (students, instructors)
- Course approval workflow
- Platform revenue & analytics
- Category & tag management
- Site settings & branding

### 11. Settings
- Profile & account management
- Notification preferences (email, push)
- Payment & payout configuration (instructor)
- Language & accessibility
